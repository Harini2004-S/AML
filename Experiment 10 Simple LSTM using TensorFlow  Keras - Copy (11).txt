
import tensorflow as tf
from tensorflow.keras import layers, models
from tensorflow.keras.datasets import imdb
from tensorflow.keras.preprocessing import sequence
import matplotlib.pyplot as plt

max_features = 10000
maxlen = 100

(x_train, y_train), (x_test, y_test) = imdb.load_data(
    num_words=max_features
)

x_train = sequence.pad_sequences(x_train, maxlen=maxlen)
x_test = sequence.pad_sequences(x_test, maxlen=maxlen)

model = models.Sequential([
    layers.Embedding(max_features, 128, input_length=maxlen),
    layers.LSTM(128),
    layers.Dense(1, activation='sigmoid')
])

model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)

history = model.fit(
    x_train,
    y_train,
    epochs=5,
    batch_size=32,
    validation_split=0.1
)

test_loss, test_acc = model.evaluate(x_test, y_test)

print("Test accuracy:", test_acc)

# Plot Loss
plt.figure(figsize=(8, 6))
plt.plot(history.history['loss'], label='Training Loss')
plt.plot(history.history['val_loss'], label='Validation Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.show()

# Plot Accuracy
plt.figure(figsize=(8, 6))
plt.plot(history.history['accuracy'], label='Training Accuracy')
plt.plot(history.history['val_accuracy'], label='Validation Accuracy')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend()
plt.show()

Program 1 – Central Tendency and Measure of Dispersion
1. Definition
Central Tendency is a statistical method used to identify the central or average value of a dataset.

It includes:
- Mean
- Median
- Mode
Measure of Dispersion is used to measure how much the data values are spread out from the central value.

It includes:
- Variance
- Standard Deviation
2. Formulas
Mean
\[
Mean = \frac{\sum X}{N}
\]

Where:
- \(X\) = Data values
- \(N\) = Total number of values
Median

For odd number of values:
\[
Median = \left(\frac{N+1}{2}\right)^{th}\ value
\]

For even number of values:
\[
Median = \frac{\text{Two middle values sum}}{2}
\]

Mode: Most frequently repeated value.

Variance (sample variance)
\[
s^2 = \frac{\sum(X-\bar X)^2}{N-1}
\]

Standard Deviation
\[
s = \sqrt{s^2}
\]

3. Purpose of using
- Mean – To find average value.
- Median – To find middle value.
- Mode – To identify frequently occurring value.
- Variance – To measure data spread.
- Standard Deviation – To understand how far values deviate from the mean.

Program 2 – Linear Regression and Multiple Linear Regression
1. Definition
Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values by identifying the relationship between input and output variables.

Multiple Linear Regression is used to predict a continuous output using two or more independent input variables.
2. Formulas
Simple Linear Regression
\[
Y = mX + C
\]

Where:
- \(Y\) = Predicted output
- \(X\) = Input variable
- \(m\) = Slope
- \(C\) = Intercept
Multiple Linear Regression
\[
Y = b_0+b_1X_1+b_2X_2+\cdots+b_nX_n
\]

Where:
- \(Y\) = Predicted output
- \(X_1,X_2\) = Input variables
- \(b_0\) = Intercept
- \(b_1,b_2\) = Coefficients
Mean Squared Error (MSE)
\[
MSE = \frac{1}{N}\sum(Y_i-\hat Y_i)^2
\]

Root Mean Squared Error (RMSE)
\[
RMSE = \sqrt{MSE}
\]

R-Squared
\[
R^2 = 1-\frac{SS_{res}}{SS_{tot}}
\]

3. Purpose of using
- To predict house prices.
- To predict salary based on experience.
- To predict sales based on advertising.
- To understand the relationship between variables.
- To compare actual and predicted values.

Program 3 – Logistic Regression
1. Definition
Logistic Regression is a supervised Machine Learning classification algorithm used to predict the probability of a categorical outcome.

It is commonly used for binary classification and can also handle multiple classes.

In this lab, it is used to classify Iris flowers into different species.
2. Formula
Sigmoid Function
\[
P = \frac{1}{1+e^{-z}}
\]

Where:
\[
z = b_0+b_1X_1+\cdots+b_nX_n
\]

- \(P\) = Predicted probability.
- \(e\) = Mathematical constant.
- \(z\) = Linear combination of input features.
Sigmoid converts the output into a value between 0 and 1.

For multiple classes, Logistic Regression can use the Softmax function:
\[
P_i = \frac{e^{z_i}}{\sum_j e^{z_j}}
\]

3. Purpose of using
- To classify data into categories.
- To predict Pass or Fail.
- To identify Spam or Not Spam.
- To classify flower species.
- To estimate class probabilities.

Program 5 – K-Nearest Neighbour and Naive Bayes
1. Definition
K-Nearest Neighbour (KNN) is a supervised Machine Learning algorithm that classifies new data based on the majority class of its nearest neighbours.

Naive Bayes is a supervised probability-based classification algorithm based on Bayes' theorem. It assumes that features are conditionally independent given the class.
2. Formulas
KNN – Euclidean Distance
\[
d = \sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
\]

Where:
- \(x_i,y_i\) = Feature values.
- \(d\) = Distance between two data points.
KNN identifies the nearest K points and predicts the majority class.

Naive Bayes – Bayes Theorem
\[
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
\]

Where:
- \(P(A|B)\) = Posterior probability.
- \(P(B|A)\) = Likelihood.
- \(P(A)\) = Prior probability.
- \(P(B)\) = Evidence.
3. Purpose of using
KNN:
- To classify data based on similarity.
- To identify nearby data points.
- To predict flower species.
Naive Bayes:
- To classify data using probability.
- To perform spam detection.
- To perform text classification.
- To predict flower species.

Program 6 – Decision Tree Classification
1. Definition
Decision Tree is a supervised Machine Learning algorithm used for classification and regression. It makes decisions using a tree-like structure containing conditions and branches.
2. Formula
One important formula used in Decision Tree is Entropy.
\[
Entropy(S)=-\sum_{i=1}^{n}p_i\log_2(p_i)
\]

Where:
- \(S\) = Dataset.
- \(p_i\) = Probability of each class.
Information Gain
\[
IG = Entropy(parent)-
\sum_j\frac{|S_j|}{|S|}Entropy(S_j)
\]

Information Gain helps select a suitable feature for splitting the data.

Program 7 – K-Means Clustering
1. Definition
K-Means Clustering is an unsupervised Machine Learning algorithm used to divide a dataset into K groups or clusters based on similarity.

Each cluster has a centre point called a centroid.
2. Formula
Euclidean Distance
\[
d(x,\mu)=\sqrt{\sum_{i=1}^{n}(x_i-\mu_i)^2}
\]

Where:
- \(x\) = Data point.
- \(\mu\) = Cluster centroid.
Centroid Calculation
\[
\mu_k = \frac{1}{N_k}\sum_{i=1}^{N_k}x_i
\]

K-Means Objective Function
\[
J = \sum_{k=1}^{K}\sum_{x_i\in C_k}
\|x_i-\mu_k\|^2
\]

The algorithm tries to minimize the distance between data points and their cluster centres.
3. Purpose of using
- To group similar data points.
- To identify customer segments.
- To group similar products.
- To identify patterns in data.
- To perform data clustering without predefined labels.

Program 9 – Autoencoder
1. Definition
Autoencoder is an unsupervised Deep Learning neural network used to learn compressed representations of input data and reconstruct the original input.

It consists of two main components:
1. Encoder – Compresses input data.
2. Decoder – Reconstructs the input data.
2. Formula
Encoder
\[
Z=f(WX+b)
\]

Decoder
\[
\hat X=g(W'Z+b')
\]

Where:
- \(X\) = Original input.
- \(Z\) = Compressed representation.
- \(\hat X\) = Reconstructed output.
- \(W,W'\) = Weights.
- \(b,b'\) = Biases.
Reconstruction Loss

A common Binary Crossentropy formula is:
\[
L=-\frac{1}{N}\sum_{i=1}^{N}
[x_i\log(\hat x_i)+(1-x_i)\log(1-\hat x_i)]
\]

This measures the difference between the original input and reconstructed output.
3. Purpose of using
- To compress data.
- To reconstruct images.
- To remove noise from images.
- To learn important data features.
- To reduce dimensionality.
- To identify unusual patterns in some applications.
In your lab, Autoencoder is used to reconstruct MNIST handwritten digit images.

Program 10 – Simple LSTM
1. Definition
Long Short-Term Memory (LSTM) is a type of Recurrent Neural Network (RNN) used to process sequential data and learn long-term dependencies.

It uses special gates to control which information should be remembered, updated or forgotten.
2. Important formulas
LSTM has three main gates.

Forget Gate
\[
f_t=\sigma(W_f[h_{t-1},x_t]+b_f)
\]

Decides which previous information should be forgotten.

Input Gate
\[
i_t=\sigma(W_i[h_{t-1},x_t]+b_i)
\]

Decides which new information should be stored.

Output Gate
\[
o_t=\sigma(W_o[h_{t-1},x_t]+b_o)
\]

Decides which information should be given as output.

Cell State Update
\[
C_t=f_t*C_{t-1}+i_t*\tilde C_t
\]

The cell state stores important information.

Sigmoid Function
\[
\sigma(x)=\frac{1}{1+e^{-x}}
\]

3. Purpose of using
- To process text data.
- To perform sentiment analysis.
- To analyse sequential information.
- To predict time-series values.
- To learn relationships between previous and current inputs.
In your lab, LSTM is used to classify IMDB movie reviews as positive or negative.
